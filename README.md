## Klasifikācija
- Latvija nav vīna stils un nav sortimenta filtra.
- Pussauss (полусухое) ir atsevišķa kategorija no Pussalds (полусладкое) un Salds (сладкое).
- Filtri kursā atdalīti: Sauss, Pussauss, Pussalds, Salds.
- Produkti tiek grupēti pēc to norādītā stila, nevis pēc nosaukuma, krāsas (piemēram, Rosé) vai izcelsmes valsts.
